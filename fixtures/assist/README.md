# Assist fixtures

Local-only progressive enhancement for **Assist & illustrative overlays** (off by default).

| Asset | Used for |
| --- | --- |
| `rfmo-vme-closures.geojson` | Illustrative RFMO VME / bottom-fishing polygons on EIA neighbourhood |
| `treaty-excerpts.json` | Corpus-ask Agreement snippets |
| `/public/assist/gfw-high-seas-effort.png` | Unlabelled high-seas apparent fishing-effort crop on a few ABMT stubs |
| `/public/assist/isa-ccz-reserved-areas.jpg` | ISA Clarion-Clipperton exploration / reserved-areas map on the CCZ ABMT stub |

The fishing-effort image is a demo mosaic from Global Fishing Watch public AIS fishing-effort COG tiles (mid-ocean / high seas, no coast labels). The ISA image is a web-sized crop of ISA map sheet 0090 (Clarion-Clipperton reserved areas). Neither is operational GIS for filing.
